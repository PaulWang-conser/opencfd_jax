# 原码 OCFD vs JAX：单步对拍（WENO7 + CD8）

- 算例：`channel_case_iiA/quick`（Case iiA，Lusher & Coleman 2023），网格 `(Nx,Ny,Nz)=(96,97,64)`，
  `Re=190.7`、`Ma=0.0955`、`T_REF=300 K`、`Pr=0.7`、等温冷壁 `Tw=1`、体积力 `F=1`、`DIF_BOUND=0 0 1 1 0 0`。
- 口径：无粘 `WENO7`（原码 303）、粘性 `CD8`、FP64、`dt=5e-5`、**只推 1 步**。
  原码用 WSL 里的 `ocfd_p1_1/build/opencfd-dump.out`（main_dump 版，跑完 1 步即停并 dump）；
  JAX 用 `build_case + build_rhs + rk3_step_stages`（与 `main.py` 同一条链）。
- 关键约定：**`--forcing-work off`**。原码 `channel_body_force_kernel` 只做 `du[1] += F*rho`，
  没有 `rho*u*G` 做功项；JAX 的 `--forcing-work` 缺省是 `on`，不显式关掉会让 `rhoE` 每步多
  约 `1e-3` 的系统差（本次实测：关掉前 worst 1.15e-3，关掉后 1.02e-7）。
  第 0 步的两条 channel 基准已按 `off` 重新生成。

## 0. 结论（2026-11-17 修正后，以本节为准）

> 下面第 1~7 节是**修正前**的记录（保留作定位过程）。真正的根因不是壁面格式，
> 而是 `_weno7_face_P` 的 epsilon 口径：JAX 用 `(eps² + S)`（`eps=3.456e-4` ⇒
> 有效加性项 1.19e-7），原码 `OCFD_Schemes.cu:643` 用 `(3.456e-4 + S)`，差 2900 倍。
> 在贴壁带 `u→0` 使分裂通量很小、`S ≲ eps`，权重被 epsilon 主导，所以这个口径错误
> 表现为"只在壁面附近、随距壁距离衰减"的假象，看上去像边界格式不一致。

| 位置 | 修正前 | 修正后 |
|---|---:|---:|
| du1 rho（全场最坏） | 2.02e-04 | **4.11e-12** |
| du1 rhoE | 7.33e-06 | **1.97e-09** |
| du1 rhov | 1.14e-04 | **8.53e-10** |
| Q1 rho | 9.27e-09 | **2.00e-15** |
| Q1 rhoE | 1.02e-07 | **3.98e-13** |
| du2 rhoE（最坏） | 3.00e-03 | **2.49e-09** |

分区也不再区分：du1 贴壁带 4.11e-12 vs 内区 1.81e-12（rho），两者同量级。
按 1e-12 判据仍是 FAIL（worst 2.49e-9，全部是 rhoE/rhov 的 1e-9 级残量，
相对量 7e-14），但"壁面 vs 内区"的分层结论已经作废。

### 0.1 怎么找到的（UP7 逐层排查）

原码 `UP7`（301）与 WENO7（303）**共用同一套壁面宏** `boundp1/boundp2/boundm1/boundm2`
（`OCFD_UP7_P_kernel` 只把 `ib1` 从 3 改成 4，边界带覆盖的面完全相同），所以换成 UP7
只改内区重构、不动壁面处理。两侧都换成 UP7 后单步对拍：

| 场 | du1 max\|diff\| | Q1 max\|diff\| |
|---|---:|---:|
| rho | 2.90e-12 | 1.55e-15 |
| rhoE | 7.37e-10 | 3.98e-13 |

⇒ 分裂（Steger-Warming）、度量链、差分、粘性 CD8、壁面带、壁面 BC **本来就逐位对**，
2e-4 的残差 100% 属于 WENO7 重构本身。再逐项比对 `OCFD_weno7_kernel_P`（`OCFD_Schemes.cu:617`）
与 `_weno7_face_P`，唯一不一致的就是加性项由 `3.456e-4` 变成了 `eps²`。

目录：原码 UP7 的落点在同级的 `../channel_up7/`（`opencfd-scu.in` 只改 `SCHEME_INVIS = UP7`）。

## 3. 差异的空间分布（关键）

`du_krk1` 与 `Q1` 按壁法向行（j=0 是下壁、j=96 是上壁）分开统计：

| 场 | du1 贴壁带 | du1 内区 (j=12..84) | Q1 贴壁带 | Q1 内区 |
|---|---:|---:|---:|---:|
| rho | 2.02e-04 | 6.10e-07 | 9.27e-09 | 2.93e-11 |
| rhou | 1.09e-04 | 2.67e-08 | 4.30e-09 | 4.72e-11 |
| rhov | 1.14e-04 | 4.57e-08 | 5.34e-09 | 1.28e-10 |
| rhow | 1.25e-04 | 5.21e-08 | 4.41e-09 | 4.08e-11 |
| rhoE | 7.33e-06 | 1.19e-09 | 1.02e-07 | 1.78e-09 |

`rho` 的逐行 max\|diff\|（du1）随距壁距离衰减：

```text
j=1  2.0e-04    j=5  3.0e-05    j=10 2.7e-06    j=20 7.7e-08
j=30 5.8e-09    j=40 1.5e-09    j=48 5.6e-14（上壁对称，j=95 1.6e-04）
```

即：**差值从壁面出发单调衰减，到中轴已是 1e-9~1e-14**。这是"贴壁/边界带
离散不同"的典型指纹；若内区 WENO7 重构或通量分裂有错，差值会在全场同量级出现，
而不会衰减掉 5 个量级。

另一条硬证据：`j=0` 与 `j=96` 的动量差**恰好为 0**（两侧都把壁面动量置零），
rho 的壁面差 3.5e-10，rhoE 的壁面差 6.8e-08——说明壁面本身就是当前残余差异的源头。

## 4. 结论与判定（修正前的判断，已被 §0 推翻）

- 严格判据（1e-12）下：**FAIL**，worst = 3.0e-3（du2 的 rhoE，位于 j=96 贴壁带）。
- 当时按区域判读：内区 du 到 6e-7、末态内区 1.8e-9，剩余差异集中在贴壁带且随距壁衰减，
  于是误判为"壁面/边界带离散不同"，指向 `boundary.py`。**这个判断是错的**：
  差别其实是 WENO7 的 epsilon 口径，只是恰好被贴壁带的小通量放大。
- 与第 0 步基准（`experiment/baseline/channel_1step`）对照原码末态：
  rho 9.3e-9、rhou 4.3e-9、rhov 5.3e-9、rhow 4.4e-9、rhoE 1.0e-7，
  与上面"从原码 step0 出发"的结果同量级——说明基准与对拍两条路的差异已收敛到同一残余。

## 5. 复核一：du 的量级不是"发散"

`du` 是守恒量的时间导数（通量散度），它的量级是 `场量 × 速度 / 网格步长`，跟是否发散无关：

| 量 | 值 |
|---|---|
| rho / \|u\|max / rhoE | 0.978–1.3692 / 23.58 / 268–546 |
| dy（壁法向） | 1/96 ≈ 0.0104（按 Reτ≈190 折算约 2 个壁面单位，DNS 级分辨） |
| 单个面通量尺度 rhoE·u/dy | ≈ 1e6 |
| du_rhoE 最大值 | −3.755e4（≈ 上面尺度的 4%，即相邻面大部分抵消后的残量） |
| dt·max\|du_rhoE\| | 1.878，相对 rhoE≈386 是 **0.49%/步** |
| 连跑 100 步（dt=5e-5） | mean rhoE 386.2928 → 386.2054（**−0.023%**），全程 `nan=False`，120.6 s |

所以 3.8e4 只是"1/dy 尺度"，判据应看 `dt·du/场量`（≤0.5%）与长跑有界性（100 步单调微降，
是冷壁在带走黏性耗散热，不是指数增长）。两套代码在同一状态给出的 du 差 3e-3，
相对 3.66e4 只有 **8e-8**。

## 6. 复核二：壁面差分到底是什么格式

**原码（`src/OCFD_Schemes.cu:667` + `src/OCFD_bound_Scheme.cu:671-804`）**：WENO7 的 P 面内核
声明 `ia1=-3, ib1=3`，宏 `boundp1/boundp2` 在 `coords<=3`（以及上界对称 3~4 个面）逐点换成
降阶单侧公式，**其余面才走全局 WENO7**：

| 面（自壁面起） | 用的公式 | 阶 |
|---|---|---|
| 0 | `f_i`（一阶迎风，直接取值） | 1 |
| 1 | `(2f_i+5f_{i+1}-f_{i+2})/6`（`P_lift`，单子模板⇒权重抵消） | 3 点单侧 |
| 2 | `P_lift_plus`：q03 与 q13 两子模板 WENO 加权 | WENO5(2 子模板) |
| ≥3 | 标准三子模板 WENO5（`P`） | WENO5 |
| ≥4 | 全局 WENO7 | 7 点 |

上界对称：最后一面对 `f + 0.5·(f−f_{-1})`（`minmod2` 同参数⇒线性外推）、次面 `P_right_plus`、
再往里 `P`。粘性侧同理有 `bound2` 的单侧 CD8，`DIF_BOUND = 0 0 1 1 0 0` 只开 y 两侧。

**JAX 侧已经实现同一套**：`schemes.flux_band_faces`（P: `(-3,3)`、M 走 P 宏）+
`viscous.cd_along_axis(bound=...)`。用开关实测证明它不是"忘了做单侧"：

| 变体 | du1 rho @j=1 | du1 rhoE @j=1 |
|---|---:|---:|
| 全开（对照原码的原口径） | 2.0e-4 | 7.3e-6 |
| 关掉无粘面通量带 | **3.2**（差 4 个量级） | **2.1e3** |
| 关掉粘性单侧 CD8 | 2.0e-4（rho 不受影响） | **2.8e2** |

## 7. 复核三：剩余 2e-4 的性质（下一步的入口）

- 关/开两个壁面带，**j≥4 的差值完全不变**（三个变体的 j=4/5/10 逐位相同）——
  说明残留不是面通量带公式本身，而是"两个带之外"的公共项。
- 相对误差（rho，逐格 |diff|/|du| 中位）随壁距单调衰减：
  `j=1 2.1e-5 → j=4 7.0e-6 → j=12 8.5e-9 → j=48 6.1e-12`。
- 下一步的两条硬路线：① 把原码也换成 `UP7`（与 JAX `--scheme UP7` 同口径）做 bisection：
  若残差图案与量级不变，问题在分裂/差分/度量链而非 WENO7 权重；② 在原码 dump 里加一个
  面通量输出（`tmp_r/tmp_l`），逐面比对 j=1..4 的具体值。

**① 已执行（见 §0.1）：UP7 口径残差 1e-12~1e-9 ⇒ 分裂/差分/度量/BC 本来就对，
残差全在 WENO7 重构，根因是 epsilon 被平方。修正后全场 1e-9 以内。**
现在只剩 rhoE/rhov 的 1e-9 级残量（相对 7e-14），若还要往下压，路线 ② 依然有效，
但优先怀疑的是 M 侧面通量带（`m_boundary="p"`）的模板偏移，而不是 rho 类场。
